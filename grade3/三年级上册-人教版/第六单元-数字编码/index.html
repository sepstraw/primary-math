第六单元 · 数字编码

🔢 一串数字，能装下很多信息

1编码是什么

用数字（或字母）按一定的规则代表信息，就叫编码。

  • 每几位代表一样东西，位置不同，含义不同
  • 规则是全国统一的，所以谁的号都能看懂
  • 好处：短、唯一、机器能读

编码不是乱编的：先定规则，再填数字。

2身份证号码：18 位，四段

点任意一位数字，看它属于哪一段。

地址码（6 位） 出生日期（8 位） 顺序码（3 位） 校验码（1 位）

点一位数字试试。

3邮政编码：6 位，也是分段

2 1 0 0 0 0

  • 前 2 位：省（直辖市、自治区）
  • 第 3 位：邮区
  • 第 4 位：县、市
  • 后 2 位：投递局

越靠前的位，管的地方越大；越靠后，管得越细——编码都是「从大到小」排的。
